# Andika

[Andika](https://software.sil.org/andika/) by SIL International is a typeface
designed for beginning readers. It uses the single-story "a" and "g" that
children learn to write, and it keeps easily confused letters (b/d, p/q, I/l/1)
clearly different.

These files are the Latin subset (regular and bold) in WOFF2 format, taken from
the [`@fontsource/andika`](https://fontsource.org/fonts/andika) package (5.3.0).
They are served from this site, so the game never contacts a font service.
